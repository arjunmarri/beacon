BeaconMac

A lightweight native macOS multi-app deployer and traffic-light monitor built in SwiftUI. Clone remote Git repositories, verify Vite & Node.js dependencies, build and deploy multiple local apps, manage background startup natively via Apple launchd with live tail -f logs and IOKit / caffeinate -s sleep prevention, and monitor Ollama LLMs and Claude API health — backed by macOS Keychain.

Frequently Asked Questions

Full Setup Guide
How do I add a Git repository and deploy a local Vite or Node.js app?

Install BeaconMac's App-Sandbox hook scripts once, then click + Add Local App inside BeaconMac. Paste any HTTPS or SSH Git URL (or pick directly from your connected GitHub repositories), choose a Vite + Node, Node.js Server, or Next.js preset, set your local folder and target local URL (such as http://localhost:5173 or http://127.0.0.1:3000), and click Clone & Deploy. 

./swift-app/BeaconMac/Scripts/install-sandbox-scripts.sh com.beaconmac.app
Do I need a .env file, or how does macOS Keychain management work?

BeaconMac requires no .env file. Paste your GitHub Personal Access Token and Anthropic Claude API key directly inside the app — both are stored encrypted in your macOS Keychain (Security.framework), displayed only as masked hints, and automatically redacted from all logs and terminal output.

For secrets needed by your individual deployed apps, keep an untracked .env.local inside each app's folder or inject Keychain values via security find-generic-password in the app's Start Command.

How do private Git repositories authenticate during clone and pull?

BeaconMac uses your Keychain GitHub token to list repositories and poll for new commits via the GitHub API. Local git clone and git pull commands executed by beacon-deploy.sh use your Mac's native Git credentials — either an SSH key stored in Keychain or macOS's osxkeychain credential helper: 

ssh-add --apple-use-keychain ~/.ssh/id_ed25519
# or for HTTPS clones:
git config --global credential.helper osxkeychain
How can I verify if my local SSH agent is correctly authenticated for Git?

Verify that your macOS SSH agent has your private key loaded and test SSH connectivity directly against github.com in Terminal. A properly authenticated agent responds with Hi <username>! You've successfully authenticated: 

# List keys currently loaded in your local SSH agent:
ssh-add -l

# Test SSH authentication to github.com:
ssh -T git@github.com
How does BeaconMac use Apple's launchd for background startup?

Toggle Startup on any managed app, then click Install & Start launchd in BeaconMac. It writes and loads ~/Library/LaunchAgents/com.beaconmac.app.supervisor.plist with RunAtLoad and crash recovery so your local apps boot automatically even when BeaconMac's window is closed. 

# Inspect the status, PID, and state of the loaded daemon:
launchctl print gui/$(id -u)/com.beaconmac.app.supervisor

# Stop the background launchd service anytime:
launchctl unload ~/Library/LaunchAgents/com.beaconmac.app.supervisor.plist
How do I watch live server logs and prevent my Mac from sleeping?

Click Watch Live Logs (or Tail Log on any app) to open macOS Terminal.app with persistent logs under ~/beaconmac/. Keep Prevent Mac Sleep enabled to hold a native IOKit power assertion while BeaconMac is open and run caffeinate -s automatically under launchd: 

tail -f ~/beaconmac/server.log
caffeinate -s   # or System Settings > Energy / Displays
