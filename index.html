Frequently Asked Questions

Full Setup Guide
How do I add a Git repository and deploy a local Vite or Node.js app?

Install BeaconMac's App-Sandbox hook scripts once, then click + Add Local App inside BeaconMac. Paste any HTTPS or SSH Git URL (or pick directly from your connected GitHub repositories), choose a Vite + Node, Node.js Server, or Next.js preset, set your local folder and target local URL (such as http://localhost:5173 or http://127.0.0.1:3000), and click Clone & Deploy. 

./swift-app/BeaconMac/Scripts/install-sandbox-scripts.sh com.beaconmac.app
How do 1-click Cloudflare Quick Tunnels expose my local apps and Ollama?

Click Expose via Cloudflare Tunnel on any Managed Local App, Expose via Cloudflare on the Local LLM (Ollama) card, or Expose Node Host / Expose Port in the Cloudflare Tunnels view. BeaconMac silently installs cloudflared if missing, generates a sanitized config.yml, and publishes an instant HTTPS *.trycloudflare.com Quick Tunnel — with zero API token required.

For local Ollama, BeaconMac automatically sets --http-host-header localhost:<port> so Ollama accepts tunneled requests cleanly over HTTPS.

How do I load an app directly into the Built-In Node.js Server?

Open the Apps & Node Host section (default http://127.0.0.1:4173) and click Start Server. Then click + Load App Folder — or click Load in Node Host on any Managed Local App — to serve static/built folders (auto-detecting dist/, build/, out/, public/, or root index.html with SPA fallback) or proxy any local port. Browse all mounted apps anytime at http://127.0.0.1:4173/_beacon/.

How does BeaconMac store my GitHub token and keep credentials private?

BeaconMac requires no .env file. Paste your GitHub Personal Access Token directly into the GitHub Account card — it is stored encrypted in your macOS Keychain under com.beaconmac.app, displayed only as a masked hint, and automatically redacted from all terminal output, activity logs, and exported files.

BeaconMac collects zero analytics and never transmits local logs to third-party services. Read our Privacy Policy for full details.

How do private Git repositories authenticate during clone and pull?

BeaconMac uses your Keychain GitHub token to list repositories and poll for new commits via the GitHub API. Local git clone and git pull commands executed by beacon-deploy.sh use your Mac's native Git credentials — either an SSH key stored in Keychain or macOS's osxkeychain credential helper: 

ssh-add --apple-use-keychain ~/.ssh/id_ed25519
# or for HTTPS clones:
git config --global credential.helper osxkeychain
How can I verify if my local SSH agent is correctly authenticated for Git?

Verify that your macOS SSH agent has your private key loaded and test SSH connectivity directly against github.com in Terminal: 

ssh-add -l
ssh -T git@github.com
What should I do if Git clone fails with a permissions error?

A Permission denied (publickey) error during git clone usually means your SSH key is not loaded into your macOS ssh-agent or its file permissions are too open: 

eval "$(ssh-agent -s)"
chmod 600 ~/.ssh/id_ed25519
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
ssh -T git@github.com
How does BeaconMac use Apple's launchd for background startup & keep-awake?

Toggle Startup on any managed app, then click Install & Start launchd in System & launchd. BeaconMac loads ~/Library/LaunchAgents/com.beaconmac.app.supervisor.plist with RunAtLoad, crash recovery, native IOKit power assertions, and caffeinate -s so your local servers remain reachable even with the display off. 

tail -f ~/beaconmac/server.log
launchctl unload ~/Library/LaunchAgents/com.beaconmac.app.supervisor.plist
How can I install missing tools like pnpm, Bun, Yarn, Python, Go, or cloudflared?

Click Install Dependencies in BeaconMac's top bar or Menu Bar, pick your project preset (Node.js + pnpm, Node.js + Yarn, Bun, Python (python3 + uv), Go, or Custom), and BeaconMac silently installs missing tools via Homebrew or verified official downloads without leaving the app.
