BeaconMac

A lightweight native macOS traffic-light monitor built in SwiftUI for the Apple App Store. Watch local Node.js and Vite servers on any localhost port with automatic crash recovery, track Git auto-deployments, monitor local Ollama LLMs with instant model switching, and verify Claude API health — backed by encrypted macOS Keychain storage and flat-file activity logs with zero database or login required.
